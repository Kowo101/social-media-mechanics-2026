# Banner Image Generation Prompt

## For AI Image Generators (Midjourney, DALL-E 3, Flux, etc.)

---

### Primary Prompt (Landscape 16:9)
```
Clean, modern technical illustration of "Social Media Mechanics 2026" as a conceptual framework. Central hexagonal core labeled "RETENTION ECONOMY" with six radiating nodes connected by clean lines: "SIGNAL HIERARCHY" (tiered pyramid), "FORMAT MECHANICS" (format icons: vertical video, horizontal video, carousel, text), "HOOK-VALUE-ACTION LOOP" (circular 3-step arrow), "DISTRIBUTION MECHANICS" (network graph nodes), "CREATOR ARCHETYPES" (5 distinct minimalist personas), "AGENT REASONING" (AI brain + flowchart). Color palette: deep indigo (#0f172a), electric cyan (#06b6d4), amber accent (#f59e0b), white. Style: Apple/Linear.app aesthetic — minimal, precise, technical but beautiful. Subtle grid background. High contrast. 4K, crisp vector feel. No text except labels. No photorealism. Flat design with subtle depth.
```

### Alternative Prompt (Square 1:1 — for GitHub social preview)
```
Minimalist icon for "Social Media Mechanics 2026". Centered retention loop: three connected arcs (Hook → Value → Action) forming a continuous cycle, each arc a different weight (thin→medium→bold). Surrounding ring with 6 mechanical symbols: pyramid (signals), format icons, network nodes, 5 personas, brain+flowchart. Background: gradient indigo to cyan. Clean, scalable, works at 64x64. Vector style.
```

### Color Palette (Hex)
- Background: `#0f172a` (slate-950)
- Primary: `#06b6d4` (cyan-500)
- Accent: `#f59e0b` (amber-500)
- Text/Lines: `#f8fafc` (slate-50)
- Muted: `#64748b` (slate-500)

### Usage
- Save generated image as `assets/banner.png` (landscape) and `assets/banner-square.png` (square)
- Reference in README.md via relative path
- GitHub social preview: 1280x640 (landscape)

---

**Design Philosophy:** The banner should communicate "mechanics" visually — systems, loops, hierarchies, connections. Not "social media" (logos, phones, hearts). The skill is about *how it works*, not *what it looks like*.

# Social Media Mechanics 2026 — Hermes Skill

## Trigger
Use when an agent needs to understand, analyze, or strategize social media
mechanics for 2026. Load this skill when:
- User asks "why does this content work?"
- User wants social media strategy based on principles, not tactics
- Agent analyzes account/content performance mechanically
- Agent predicts content performance before posting
- User asks about algorithmic changes in 2026

## Core Knowledge (Loaded into Agent Context)

### Mechanical Framework: The 6 Pillars
1. **Attention → Retention Economy Shift** — Platforms optimize for session duration & return frequency, not impressions.
2. **Algorithmic Signal Hierarchy** — Tier 1: Watch time %, Re-watches, Private shares, Saves. Tier 2: Substantive comments, Profile visits, Link clicks. Tier 3: Likes, Public shares, Follows.
3. **Format-Mechanic Mapping** — Each format has a primary mechanical driver (swipe retention for shorts, session extension for long-form, swipe-through for carousels).
4. **Hook → Value → Action Loop** — Every successful post: Hook (0-1.5s) → Value (delivers promise) → Action (triggers Tier 1/2 signal).
5. **Platform-Agnostic Distribution** — Interest graph, collaborative filtering, freshness decay, authority compounding, cross-platform seeding.
6. **Creator Archetype Mechanics** — Educator (saves), Entertainer (re-watches), Community Builder (comment depth), Curator (shares), Documentarian (profile visits).

## Agent Behaviors

### When Loaded, The Agent Will:
1. **Diagnose mechanically** — Map user's situation to the 6 pillars
2. **Ask clarifying questions** to identify mechanical gaps:
   - "What format?" → Format-Mechanic Mapping
   - "What action do you want?" → Hook→Value→Action
   - "Which platform?" → Platform-Agnostic Distribution nuances
3. **Generate mechanistic strategy** — Specific, measurable, principle-based
4. **Predict performance** — Using mechanical proxies (hook strength, value density, action clarity)
5. **Iterate from signals** — Read retention curves, signal ratios, not vanity metrics

### Example Reasoning Pattern
```
User: "Low followers despite views."
Mechanical Diagnosis: Hook works (views), Action fails (no follow signal).
Prescription: Add explicit CTA at 80% retention mark. Test follow-conversion.
```

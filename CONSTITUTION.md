# CONSTITUTION.md

## Project: Social Media Mechanics 2026

### Purpose
This repository contains a **Hermes skill** that codifies the mechanical principles of how social media works in 2026. It is a knowledge artifact — not a tool, not a script, not an API wrapper.

### Principles

1. **Mechanics Over Tactics** — Tactics expire; mechanics persist. This skill teaches *why* things work, not *what* to post today.
2. **Platform-Agnostic** — Core mechanics apply across TikTok, Reels, Shorts, YouTube, X, LinkedIn, Threads. Platform nuances are annotations, not foundations.
3. **No Personal Data** — Zero PII, zero API keys, zero user-specific config. The skill is a pure knowledge module.
4. **Evidence-Based** — Every mechanical claim should be traceable to observable platform behavior or documented algorithmic shifts.
5. **Agent-First Design** — Written for AI agents to load, reason with, and apply. Human-readable is a bonus.
6. **Free & Open** — MIT licensed. No commercial upsell, no gated content, no telemetry.

### Governance
- **Maintainer**: Single maintainer (repository owner)
- **Contributions**: PRs for mechanistic insights, evidence, corrections
- **Releases**: Semantic versioning (mechanics change slowly; major = paradigm shift)
- **Deprecation**: Mechanics marked "deprecated" when platform behavior fundamentally shifts

### Scope Boundaries
**IN SCOPE:**
- Algorithmic signal hierarchies
- Format-mechanic mappings
- Psychological triggers (attention, retention, action)
- Distribution mechanics (interest graph, collaborative filtering, freshness)
- Creator archetype mechanics
- Agent reasoning patterns

**OUT OF SCOPE:**
- Platform-specific API usage
- Posting schedules/timezone tools
- Content creation templates
- Analytics dashboards
- Personal branding advice
- Monetization strategies

### Quality Bar
- New mechanics require: observable evidence OR platform documentation OR replicated experimental results
- Anecdotal "this worked for me" → insufficient
- "Expert says" → insufficient without mechanistic explanation
